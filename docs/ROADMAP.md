# Roadmap posterior al primer release

## Conectores próximos

1. Greenhouse.
2. Lever.
3. Ashby.
4. SmartRecruiters.
5. Hiring Room.
6. Get on Board.
7. Bumeran/ZonaJobs si existe una ruta estable y legalmente razonable.
8. EURES y portales europeos con APIs o feeds estables.

## Inteligencia de mercado

- Registrar versiones de cobertura para ajustar series temporales.
- Calcular skills emergentes con ventanas comparables.
- Normalizar salarios con tabla de tipos de cambio versionada.
- Medir company hiring velocity.
- Comparar mercado observado con las skills declaradas del usuario.

## Producto

- Notas editables desde el panel.
- Exportación de vistas filtradas.
- Comparación de dos oportunidades.
- Detección de ofertas cerradas.
- Revisión manual de muestras para calibrar scoring.

## Condición para agregar una fuente

Debe demostrar durante al menos tres corridas:

- Yield de puestos únicos.
- Porcentaje de descripción completa.
- Tasa de errores aceptable.
- Oportunidades relevantes o señal de mercado no redundante.
